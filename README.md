# Embedded_systems
This repository includes projects and other exercises proposed by the relative course from the University of Genoa MSc in Robotics Engineering during the 2026/27 academic year.

For a better view of the same project, exercises and assignments (already shown in the "Exercises + assignment + project" folder proposed in this repository) see the "Course_files_from_Paro2621" folder. The files in there were retrieved from a collegue of mine who participated at the same course. In that folder there are all the README files written to describe each exercise, including the assignments. For the final project, the README file is put in the folder with the same name.
If you want to check his other works you can go to his GitHub profile https://github.com/Paro2621 or even https://codeberg.org/Paro2621.
